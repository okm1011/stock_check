# stock_check

바이낸스 USDT-M 무기한 선물 **전 종목**을 한 화면에서 보고, 분류·메모를 붙여 두는 워치리스트입니다.

1차 범위:

- 상장 중인 USDT 무기한 전부
- 번호, 심볼, 현재가, 선택한 기간의 변동률
- 웹에서 분류/메모 수정 (새로고침 후에도 유지)
- 시세는 **최소 1분마다** 갱신

## 실행

```bash
cd ~/Programming/stock_check
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app
```

브라우저: [http://127.0.0.1:8090](http://127.0.0.1:8090)

## 기간

상단 **기간**에서 `15m / 1h / 4h / 24h / 7d` 를 고릅니다.

- `24h`는 바이낸스 24시간 통계를 바로 씁니다.
- 나머지 기간은 1분마다 쌓인 가격 스냅샷으로 계산합니다. 앱을 처음 켠 직후엔 과거가가 없어 `—`가 보일 수 있고, 백그라운드에서 해당 시점의 1분봉을 채워 넣습니다.

분류·메모는 `data/stock_check.db`에 저장됩니다. 설정 웹에서 바꾼 값과 같습니다.
